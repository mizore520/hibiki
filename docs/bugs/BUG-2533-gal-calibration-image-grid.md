## BUG-2533 · 人工中心拟合无法求字号、换行及续行缩进

当前候选已在后续轮次改为 OCR 提供位置、Hook 提供正文、规则格拟合推进和缩进；下面“无需 OCR”描述的是初版历史。第十三轮补充窄 ASCII 空格与续行共用原点，具体实现和证据见 [BUG-2542](BUG-2542-gal-cross-game-calibration-still-not-general.md) 与 [当前交接](../personal/archive/GAL_LOOKUP_HANDOFF.md)。不要求用户逐字点中心，不将同一句首尾框的留白拆成不同布局。

- **报告**：2026-09-18（用户：无法精确点字符中心，字号字距不知如何设置，多行溢出及续行缩进不一致）
- **真实性**：✅ `fushi/lib/src/lookup/gal_lookup_calibration_draft.dart:197` 的旧拟合只求平移与字距，依赖已有字号/换行；DirectWrite 预览与游戏字体/排版不相同，增加人工中心点不能求出遗漏参数。每个真实截图的溢出原因不一，不能把提示一律归为框高度不足。
- **[x] ① 已实现候选** — 初版提交 `88bf7d6d93`：新增冻结截图的笔画投影测量，用已知 Hook 正文匹配规则字格，求原点、字距、行距、行高、换行列数与续行缩进；无需 OCR、字体识别或引擎特例。第五轮修订改为共同使用训练样本，保留独立验证分组，避免仅选一张图遗漏普通/引号续行的不同缩进。多解、字符不适用、图文不符或 native 预览拒绝时不改草稿。可选严格 `layout.cellGrid` 同时进入预览与实际查词，旧字体排版作为显式高级选项保留。
- **[x] ② 已加自动化测试** — `gal_lookup_calibration_image_fit_test.dart` 覆盖无人工中心点的测量、不同续行缩进、尾部空行、留出图不一致及多解拒绝；连同草稿、profile、samples dialog、workbench 共五个定向套件，实际执行 49 项、退出码 0。native `attached_text_layout_test.cpp` 15 cases 通过；`flutter_window.cpp` 单对象编译通过。私有离线诊断将用户提供的两行截图与已保存短句一起检查通过，素材未入库；此结果不代表游戏运行期验收。
- **备注**：仅覆盖可验证的横排等宽字格。至少一张有自动换行的完整多行图才能确定列数；显式换行不能单独证明软换行容量。对黑边、比例变化、比例字体、注音与特殊控制字符不宣称通用精确适配。图片和对白仅在本机草稿/临时目录，不入库、不上传。真实游戏体验仍待用户验收。

### 第五轮：完整真实样本复现后的修订

用户反馈真实两行/三行仍无法自动对齐。读取八张原始客户区截图，在用户已保存的大致选区稳定复现：`gal_lookup_calibration_image_fit.dart` 的 `_measure` 将远离正文的一小撮背景亮点并入行边界，导致 `_fitSample` 认为正文占据错误宽度；另一个三行样本的底部背景亮点把行首拉到窗口左边。诊断性收窄选区后全部样本通过，证明不能要求用户依靠精细拖框消除此误差。

修订仅剔除距离正文足够远、宽度及总墨量均极小的孤立噪点，保留完整字形、短行及邻近标点；之后仍须通过全部文字/行位置的一致性检查。默认未测量状态不调用旧字体 native 预览，也不显示“字号排不下”及人工中心误差，自动结果通过后才生成字框。失败提示附具体样本编号，草稿保持原值。

定向回归覆盖粗选区的背景干扰、完整多余字形不可被丢弃、共同训练/验证分组、失败保留草稿和自动模式不使用旧字号预览。八张用户样本的私有离线检查通过，覆盖单行、两行及三行，得到共同的 27 列、普通续行不缩进、引号续行缩进一格。完整验证结果见个人任务记录第五轮；真实游戏运行期命中仍待候选构建后验收。
